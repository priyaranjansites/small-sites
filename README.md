# small-sites

A responsive directory homepage for a collection of small websites.

## Customize the site links

Open `index.html` and edit the four directory cards:

- Change each `Site One` / `Site Two` title and description to match your page.
- Update the matching `href` (currently `./site-01/` through `./site-04/`) to the page folder or URL.
- Duplicate or remove a `<a class="site-card ...">` block to add or remove sites.

Open `index.html` in a browser to preview the homepage. No build step is required.
